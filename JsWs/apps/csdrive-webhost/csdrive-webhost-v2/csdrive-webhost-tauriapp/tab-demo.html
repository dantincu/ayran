Tab init demo

Every click below simulates a real app opening another document/view as a new tab in this same window: it first updates the page's own URL (via history.pushState, so location.href encodes which resource is "open"), calls init_window_tab with the app version, that URL, and a resource type key, then — after a short simulated load — calls update_tab_resource with the two-line styled label to show for it. The window itself is identified implicitly (this window's own Tauri label) — nothing about it is ever passed explicitly.

This page also registers an icon for its demo-doc resource type on load. The very first tab it ever opens (a first-time appVersion for this html file) makes the backend ask for it via a request-resource-icons event — watch the Windows tab in the admin app to see the icon show up next to the tab once that round trip completes.
