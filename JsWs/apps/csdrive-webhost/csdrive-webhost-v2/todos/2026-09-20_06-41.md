2. I just now saw that we can close the main window of our app (where the admin app runs) while secondary windows stay open. So let's make it that when we close the main app window, there should be a listener for an event like "closing" or "beforeClose" that allows us to first suspend all secondary windows (so close actual windows), and only then to close the main app window.
