Regarding the javascript code editors, let's mimic the behavior of other popular javascript editors by automatically appending matching closing brackets and quotes when the user types an opening bracket or quote (applies to all 3 kinds of brackets: rounded, square and curly; and also applies to both single and double quotes). In addition, whenever the user presses the ENTER key when the caret is inside a pair of braces, the closing brace should sit on a third line on the same indenting level as the current line and the caret should then sit on the second line which should readily be indented 1 level more than the first line. And the indent for javascript should be 2 spaces. And generally, when pressing the ENTER key from an already indented line, the newly created line should itself be indented accordingly (normally the same as the original line except when the newly created line is part of a nested block of code, like the situation described above).
