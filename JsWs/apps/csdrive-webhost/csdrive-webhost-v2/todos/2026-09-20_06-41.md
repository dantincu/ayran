I just realised there could be a possible inconsistency about how we save the state for pages where we have paginated list because we change the page size globally everywhere: let's say we go to a place and navigate to a certain page having a certain page size. Then we move to a different place, change the page size, then come back to the first place, we have a different page size than was when we saved the state for this first place. Given the new page size, what is the page number that is restored here? If its the same page number that was stored when the page size was different, we'll see different records, that is unwanted behavior. If that is the case, let's find a universal way to save states for paginated lists: either save the number of records skipped instead of the current page number, or save both the page number and the page size at the moment of saving the page number.
