# Note custom actions

Everywhere in the Notes App let's put an icon button that when pressed will open a popup modal that will contain an iframe rendering a certain html page as a web app - html file whose location will be configurable by the user per notebook. Once configured, it can be reset (and show these config/reset buttons on the modal header, so totally unambigously from the custom page itself) and most importantly, its path saved as a setting record in the notebook's internal folders pair ("03" the short name folder and "03-[note-book]" the full name folder - so inside the "03" folder in a json file somewhere). Since we can have this functionality everywhere in our Notes App, when outside the scope of a notebook, a "global" custom web page will be shown and its path saved in a global Notes App setting record (so it will live in an sqlite database file). Finally, let's call this functionality "User Action" or "Custom User Action" but only show an icon for that launch button and offer an explanation somewhere in an icon button in the header of the modal that pops up.
