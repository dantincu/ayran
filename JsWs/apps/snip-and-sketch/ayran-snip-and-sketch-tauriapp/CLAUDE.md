# Ayran Snip and Sketch Tauri App

Let's create a Snip & Sketch Tauri app (for both mobile and desktop). It should offer options to edit an image by cropping it (create a rectangle over the image, drag its sides and corners, move it, scale it - and then selecting a slice from the image that is contained by the resulting rectangle). The user should be able to apply multiple crops before saving it as a new image file. The edited image can be either an existing image on the local device or a screenshot of the current screen that this app will take on behalf of the user. The screenshot should function as follows: an icon button should be shown that is drawn over other apps (so it will be visible when this app loses foreground) and when pressed, it removes itself and then the app's background takes the actual screenshot. From then on, the image can be cropped and saved as the user wants.

A special feature offered by this app is the ability to save crop rectangle coordinates. Choosing this option will save to indexedDb the coordinates of the latest crop operation: the coordinates of the top-left and bottom-right corners of the rectangle relative to the top-left corner of the edited image (that is the version of the image before the last crop, not the original image, when multiple crops are performed during the same session). When saving the coordinates of a crop, the user should be asked for a name for the saved crop, the default of which should be the coordinates values. Choosing to use a saved set of crop coordinates should show a crop rectangle on the currently edited image (and let the user trigger the actual crop operation or edit the coorinates further, as they want).

The state of this app should be persisted to indexedDb.
