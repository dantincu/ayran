# Tab Shortcuts

A Chromium-based browser extension companion to the Taskbar Shortcuts Windows app
(`../../taskbar-shortcuts/taskbar-shortcuts-v1`).

Inside such a browser, pressing a certain key combination should show a new tab (or an
existing tab if it has already been opened by the user) showing a list of open tabs, each
with a number in front of it and a textbox to type the number (the textbox being readily
focused). Choosing a tab will close the tab for this extension.
