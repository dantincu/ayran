Regarding the system of keyboard shortcuts from docs\features\features.md, where we say "we should be able to reach the page's top row of icon buttons using the Alt+Shift+J key combination": while we can navigate buttons using the arrow keys and key combinations like Alt+N etc., there are pages in our app where there is a second page-specific top header (mainly our text editor has its own row of buttons). The buttons on that second page-specific header should also be navigable in the same fashion the page's top header. So pressing Down Key will navigate to the first button on that row. Likewise, pressing Up Key will navigate back to the first button on the page's top row.
