In this case, let's create an "experimental code editor" for which the user will be able to opt in as a setting item from the admin app. This experimental code editor will bypass the react rerendering completely and not use dangerouslySetInnerHtml attribute at all. Does this sound like it could remove the flicker and not cause other issues? Yes, I'm aware that it is a huge architectural change, so let's have a discussion about this.
