Tab init demo

Every click below simulates a real app opening another document/view as a new tab in this same window: it first updates the page's own URL (via history.pushState, so location.href encodes which resource is "open"), calls init_window_tab with just the app version and that URL, then — after a short simulated load — calls update_tab_resource with the two-line styled label to show for it. The window itself is identified implicitly (this window's own Tauri label) — nothing about it is ever passed explicitly.
