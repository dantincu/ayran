# Ayran LAN Streamer

I want to create a service that allows devices to stream the sound that is sent to their speakers (or headphones) and / or the sound captured by their microphones over the local area network. So the service (a web api with web sockets functionality) receives the sound streamed by host devices, mixes them up and broadcasts them for client devices to listen to. In order to protect the streams against unwanted listeners let's use authentication: let's require any streaming host and listener client to first authenticate to a filen (filen.io cloud storage) account in order to use our service. Then, in order for a host to stream sound it should first create a stream (that is persisted in the api) or join a stream previously created by another host and have our api combine the sounds from multiple streams into a merged one stream. Any host can create streams or delete any of the created streams (under the same filen account, of course). A single host can be streaming a single stream at any point in time. Any host can pause or resume streaming on any stream persisted on the api (again be careful that the api filters down the available streams by the filen account). Finally, a client can listen to only one (merged) stream at a time.
> 
> Let's create a single app that can act both as a streaming host or as a listener client (not at the same time though). For creating this app we should use Tauri and React. And as for the api, I think we can create it with nodejs (correct me if there's a better technology for it). The api will be hosted on a windows desktop computer (this computer - but of course I want to be able to host it from any desktop OS). Don't forget to use https for the api.
