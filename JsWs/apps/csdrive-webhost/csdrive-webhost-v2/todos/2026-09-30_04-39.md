1. There is still no way to save a randomly generated theme. And don't forget that the previously generated random theme should also be possible to save.

2. There are 2 bugs related to the auto-hiding header:
   - when it's hidden, there is still some unnecessary space between the top margin of the view port and the editor header. That unnecessary space might correspond to the vertical padding (and margin, if any) applied to the auto-hiding header. And if you just varied the header's height or max-height css property to smooth its hiding, you should also vary its padding (and margin, if any).
   - There are cases when the auto-hiding header shows and hides rapidly, making the entire page "shake" continuously. This happens when I quickly scroll to the end of the editor. Why I think it happens: first, I assume that you listen to the scroll event, and when the scroll is positive you hide the header, when its negative you show it. Then, hiding/showing the header changes the height of the scrolling container, which then might change the position of the scroll, so itself might trigger another, scroll in the opposite position, which triggers showing the header back, that now triggers yet another scroll in the other position, the header gets hidden again and so on. My suggestion: while the header hiding/showing animation happens, set up a bitflag somewhere so as to do nothing on the scroll event. So any scroll event triggered while the header hides or shows will not itself cause the header to hide or show as it's already doing that.
